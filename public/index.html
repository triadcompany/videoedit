Referências salvas

Suba vídeos cujo estilo você quer copiar. Eles ficam salvos aqui e aparecem no campo Estilo da página Criativos, na hora de gerar ou legendar. Clique em Ajustar estilo para acertar fonte, cor e corte de pausas de cada uma.

    Comece subindo os vídeos

    Seus vídeos

    O gancho abre o anúncio, o corpo explica e o CTA chama para a ação. Todas as combinações viram variações.

    Variações

    As variações aparecem aqui

    Depois de tratar os vídeos, clique em Gerar variações. Cada combinação de gancho, corpo e CTA vira um vídeo pronto para editar e baixar.

    Editar selecionadas

    Tira os silêncios longos e deixa só um respiro curto.

    Iguala o som das três partes de cada vídeo.

    Tirar edições

    Ligar uma opção só adiciona: o que o vídeo já tem é mantido.

    A prévia é aproximada. O resultado final (com animações) é renderizado ao salvar.
    Sugestão pelo silêncio

    VelocidadeA prévia já toca na velocidade escolhida
    Tire só o que sobra no começo e no fim. Se já está bom, clique em OK. Use o botão de alvo para marcar o ponto exato onde o vídeo está parado.

    Ajuste por vídeo

    Partes do vídeo

    Escolha o trecho (início e fim) e o volume de cada parte. Use Ouvir para testar o som e o botão de alvo para marcar o ponto exato do vídeo.
    Se este vídeo já tem corte de pausas e legenda, eles são refeitos em cima das novas partes (a legenda é transcrita de novo se o tempo mudar).

    Quadros da referência

    Use o conta-gotas ao lado das cores e clique em um quadro acima para copiar a cor exata.

    Estilo da legenda

    Corrija palavras erradas abaixo. Apague o texto de uma palavra para removê-la.

    Cortar respiração / pausas longas

    Tira todo silêncio maior que esse tempo, deixando só um respiro curto para não ficar seco. Trechos de vídeo sem nenhum áudio (clipe mudo) são mantidos.

    Texto na tela

    O texto fica salvo no estilo e entra sozinho ao gerar/legendar com essa referência (você pode trocar na hora de legendar). Início 0 e Fim 999 = o texto fica o vídeo todo.
